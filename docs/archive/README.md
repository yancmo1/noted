# Documentation archive

This directory contains historical reference material. Archived documents do not define the current Noted product, architecture, API, or roadmap.

Read `PRODUCT.md`, `README.md`, and the current documents in `docs/` first. If an archived document conflicts with current code or current documentation, use the current implementation and record the reason for any needed update.

The archived Pocket and Memory Garden documents are retained to explain earlier product directions. Their names, absolute paths, autonomous execution rules, and feature lists are not current instructions.

`PIVOT_PRD_POCKET_APP.duplicate.md` is retained because it was an exact duplicate of the archived root PRD when this cleanup started. It is not an additional requirement.
